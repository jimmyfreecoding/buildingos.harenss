# 04 · 获客与销售 SOP

> 目标读者：创始人（初期唯一销售）。本文把「免费大屏」从一句口号变成可复制的漏斗：目标客户画像、冷拜访话术、异议处理表、14 天试用 SOP、转化/二次销售脚本、案例与裂变。

---

## 1. 目标客户画像（ICP）

| 维度 | 理想客户 | 次优客户 |
| --- | --- | --- |
| 类型 | 仓储物流、3PL、电商仓、轻工工厂 | 办公楼、零售连锁 |
| 面积 | 10,000–100,000 sq ft | >100k（预算高但决策链长） |
| 决策人 | Operations Manager / Owner（华人仓优先） | 总部 IT 部门（不选，决策慢） |
| 痛点 | CCTV 老断、Wi-Fi 盲区、没有 IT 人、被供应商绑架 | 有专职 IT（难切入） |
| 预算特征 | 月付 <$500 可走费用，无需资本开支审批 | 需 CapEx 审批 |
| 最佳信号 | 用过「兼职网管」或「弱电供应商年维护费」 | 完全裸奔（无维护） |

**选择顺序：** 华人/熟人仓（信任快）→ 同园区转介绍 → 冷拜访。每周新增目标：10 次拜访 → 5 台试用 → 1.5 台转化。

---

## 2. 冷拜访 SOP（带 Demo 箱）

### 2.1 拜访前（15 分钟准备）
- [ ] CRM 查重，避免撞单
- [ ] 打印单页 ×2（一份留下）、NDA 空白模板、名片
- [ ] 探针充好电、便携显示器开机自检、Demo 数据预载
- [ ] 路线确认（园区地图），着装：工装 polo + 工牌

### 2.2 开场（30 秒电梯陈述）
> 「张总，我们专门给休斯顿的仓库做 24 小时 AI 网管——花兼职网管 1/10 的钱（$299/月），帮您盯着监控、Wi-Fi 和机房，断线 30 秒自动重启自愈，真出物理故障我们本地团队随时上门修。今天我们免费借您一台机房大屏，插根网线就能实时看全厂设备状态，不需要装任何软件。试用 14 天，觉得没用随时拔线拿走，您零损耗。」

### 2.3 现场演示（3 分钟，边插边讲）
1. 出示探针：「就这个小盒，插交换机空口 + 电源，HDMI 接大屏。」
2. 插上 → 3 分钟内自动扫出全网设备 → 展示拓扑：「您看，这些是交换机、摄像头、AP，都在了。」
3. 展示 CCTV 状态矩阵：「哪台黑屏、哪台掉线，这里一目了然。」
4. 展示 AI 小贴士滚动条 + 承诺：「您屏幕上看到的，就是这个盒子收集的全部数据——它只读，不碰您的账目和业务文件。」

### 2.4 签约试用（当场完成，<10 分钟）
1. 签 NDA + 《零写入承诺书》双份
2. 记录：交换机型号/IP、摄像头品牌数量、Wi-Fi AP 品牌、联系人邮箱电话
3. 约定 Day 12 电话回访 + Day 14 现场交付报告
4. 拍照（征得同意）：「给您看下装好的样子」→ 留作案例素材

## 3. 异议处理表（Top 10）

| 异议 | 回应 |
| --- | --- |
| 「数据会不会被你们偷看？」 | 「这个小盒只读，不装软件，不碰账目和文件。您屏幕看到的就是全部数据；而且我们签 NDA，写进合同违约罚则。」 |
| 「是装木马的吧？」 | 「现场可以看着我们插线，全程透明。它不做任何写入操作，拔线即停止，我们还会出具数据清除证明。」 |
| 「我们没网管也活得好好的」 | 「那 CCTV 最近断过几次？每次断多久？我们扫 3 分钟就能告诉您真实情况，反正是免费的。」 |
| 「太贵了」 | 见 03 文档锚点话术（1/10 兼职网管 + 断网货损对比）。 |
| 「我自己能盯监控」 | 「您要盯的是生意，不是 40 路摄像头。AI 7×24 帮您盯，异常才叫您，还带月度报告。」 |
| 「试用后不买会怎样？」 | 「零费用零残留，报告也留给您。14 天您看到真实价值再决定。」 |
| 「供应商已经包了维护」 | 「他们的维护是按次收费、24 小时响应吗？我们 $299 全包，还送每月 1 次上门，可以并着用，报告您留底。」 |
| 「要不要装软件到我们电脑？」 | 「完全不用。探针插交换机就行，跟您办公电脑、账房零接触。」 |
| 「我们隐私/合规有要求」 | 「我们有德州 TDPSA 合规评估与数据处理条款，可以对接您法务。」 |
| 「先看看吧」 | 不给「想想」的空窗：「那我今天先给您装上，14 天免费，Day 14 给您报告，用不用您说了算。」 |

## 4. 14 天试用转化 SOP（自动化 + 人工触点）

| Day | 触点 | 动作 | 目标 |
| --- | --- | --- | --- |
| D0 | 现场 | 部署 + 签约 + 拍照 | 信任建立 |
| D1 | 邮件 | 欢迎邮件：探针位置图 + 看板访问方式 + 24h 报告样例 | 期待感 |
| D3 | 邮件 | 首份《运行健康日报》自动推送 | 展示价值 |
| D7 | 邮件 | 中期报告（发现数 + 隐患 Top3） | 制造紧迫 |
| D9 | 微信/电话 | 电话回访：询问断网/黑屏历史，印证报告发现 | 深度绑定 |
| D12 | 电话 | **转化预演**：预告 Day 14 报告亮点 + 报价单提前发 | 消除价格惊跳 |
| D13 | 微信 | 提醒明天现场交付，确认时间 | 到访率 |
| D14 | 现场 | 演示完整报告 → 报价 → 「今天签年付 9 折」 | **签约** |
| D15 | CRM | 未签 → 进入 7 天冷却流：撤机或延期 7 天（仅一次） | 挽回 |

**转化脚本（D14 现场收尾）：**
> 「张总，这是您仓库的真实数据：3 台摄像头夜间掉线 6 次、AP2 覆盖盲区 400 平、机房交换机 2 个端口错误包超标。这些我们 24 小时帮您盯着，断了 30 秒自愈，月度还有整改报告。基础包 $299/月，今天签年付 9 折——您看是现在签，还是我把方案发给您合伙人？」

**关键动作：** 无论签不签，**当场把报告 PDF 交付**（价值留痕，便于二次跟进与转介绍）。

## 5. 二次销售与升级脚本

| 场景 | 触发 | 脚本要点 |
| --- | --- | --- |
| Basic → Pro | 设备 >30 / 多园区 / 员工常问 IT 问题 | 「您设备规模已经到 Pro 档了，加 $300 多 1 次上门 + AI 问答帮员工省时间，还享 9 折采购。」 |
| 订阅 → 工程单 | 报告发现盲区/老化设备 | 「报告第 4 页这 3 项整改，我们本地团队可以顺带做，报价单已附。」 |
| B2B → 豪宅 | 老板聊到自家装修/智能家居 | 「顺带一提，我们做高端住宅全屋智能——有线 KNX 方案，10 年不坏。您家要是有需求，我约工程师免费上门看看。」 |
| 客户转介绍 | 满意客户（NPS ≥ 8） | 「老张，您园区还有谁家也总断网？您介绍一家，送您一个月服务费抵扣。」 |

## 7. 每周销售节奏

| 时间 | 动作 | 产出 |
| --- | --- | --- |
| 周一 | 列本周 10 家拜访名单 + 预约 | 拜访计划 |
| 周二–周四 | 每天 3–4 家冷拜访 + 1 场 D14 交付 | 拜访记录入 CRM |
| 周五 | 交付报告 + 报价跟进 + 物料补充 | 漏斗更新 |
| 周六 | 复盘漏斗：拜访→试用→转化 各环节转化率，定下周动作 | 周报 |

**漏斗基准（健康值）：** 每周 10 拜访 → 5 试用（50%）→ 1.5 付费（30%）→ 每周 MRR +$500。
