> 对应反馈：探针需支持 ①拓扑探知+对话调整 ②内外网链路质量评估找薄弱环节 ③品牌/手册知识库 ④商业运维交付（稳定性/风暴/建议/配置记录）。
> 状态：本机已实现并实测 ✅；Pi 依赖项已留接口 ⏳。

## 1. 需求 → 实现映射

| # | 需求 | 实现（工具/引擎） | 本机验证 |
| --- | --- | --- | --- |

## 2. 新增工具清单（probe-1/pkg-13，14 工具）

| 工具 | 说明 |
| --- | --- |
| topology_describe | 自然语言拓扑描述（合并人工覆盖 + 薄弱环节提示） |
| link_quality | 逐设备/网关/外网/DNS 质量 + 自身无线 + 薄弱环节 |
| asset_update | 对话调整持久化：device / manual / account 三类 |
| assets_list | 覆盖后设备 + 品牌手册 + 脱敏配置记录 |

> 原有 10 工具不变（probe_ping/arp_discovery/scan_subnet/port_scan/snmp_query/inspect_rtsp/topology_build/health_report/diagnostic_report/probe_status）。

## 4. 本机实测证据（2026-08-18，10.0.0.0/24）

**链路质量（需求 2 的核心价值）：**
```
27 台设备 · 25 在线 · 5 处薄弱环节
- 10.0.0.105/.111 (Intel 电脑)：丢包 100% —— 禁 ping 或休眠（需人工核实）
- 10.0.0.7 / 10.0.0.233 (TP-Link)：丢包 33% —— 疑似无线弱信号/电源抖动
- 10.0.0.98 (手机/随机MAC)：抖动 62ms —— 无线环境不稳定
网关 0% 丢包/5ms · 外网(8.8.8.8) 0%/20.7ms/13 跳 · DNS 0%/14.7ms/8 跳
探针自身无线：SSID geeqee · 5GHz · 信道 157 · 信号 69% · WPA3
```

**对话调整（需求 1）：** `asset_update device ip=10.0.0.119 name=海康4K摄像头 type=camera notes=仓库北门` → 落盘 overrides.json → topology_describe / assets_list / 报告自动引用。

## 6. 使用方式（对话示例）

```
用户：这网络有什么问题？
探针：运行 link_quality → 报告薄弱环节（丢包/抖动/跳数）→ 给出建议

用户：10.0.0.119 是海康 4K 摄像头，接在交换机 7 口，北门
探针：asset_update device → 覆盖落盘 → 后续拓扑/报告引用

用户：把海康 DS-2CD2186G2 说明书登记一下
探针：asset_update manual → manuals.json

用户：把 NVR 登录账号记下来（10.0.0.119 admin）
探针：asset_update account → accounts.json（报告输出脱敏）

用户：出份诊断报告
探针：diagnostic_report → 含链路质量/薄弱环节/配置记录
```
