# 05 · 渠道合作与白标模式

> 目标读者：创始人、未来渠道经理。本文定义渠道合作的两种模式（分佣加盟 / 白标 OEM）、伙伴画像与招募、商务条款、生命周期管理、冲突规则与退出机制。目标：Month 4 起开放，Month 12 时渠道贡献 ≥40% 节点。

---

## 1. 两种模式对比

| 维度 | 分佣/加盟模式 | 白标 OEM 模式 |
| --- | --- | --- |
| 谁签客户 | 弱电公司（对外以自己名义） | 弱电公司（以自己品牌） |
| 你的角色 | 技术平台 + 监控中心 + 兜底上门 | 纯 SaaS 技术供应商 |
| 收入 | 月运维费 **五五分成**（各 ~$200/月/节点） | **$99–$149/月/节点** 软件授权费 |
| 工程单归属 | **100% 归弱电公司**（激励其卖工程） | 100% 归弱电公司 |
| 客户数据 | 双方共享看板 | 归弱电公司（白标后台） |
| 适配伙伴 | 有客户但没 AI/监控能力的小公司 | 有品牌、有施工能力的中型公司 |
| 风险 | 伙伴流失带走客户 | 收入薄，靠规模 |

**启动策略：** 先推**分佣模式**（门槛低、绑定深、对方没成本），伙伴跑顺 3 个月后若其客户量 >30 节点，再谈白标升级。

## 2. 理想伙伴画像（MQL）

| 特征 | 说明 |
| --- | --- |
| 公司规模 | 5–30 人弱电/安防/IT 集成商 |
| 业务 | 仓储/办公楼安防监控、网络布线、门禁 |
| 现状痛点 | 维护合同毛利低、人工 24h 响应做不到、客户流失给大厂 |
| 决策人 | Owner / 销售合伙人（<3 人决策链） |
| 地域 | 休斯顿大区，与自营园区**不重叠**（见 §6 冲突规则） |
| 信号 | 已给仓库客户做「年维护费」合同（可被替换升级） |

**招募渠道：** 园区内弱电工程队、LinkedIn 本地集成商群、华人商业协会、行业展会（如 CEDIA/ISC West 休斯顿站）、现有客户推荐。

## 3. 商务条款模板

### 3.1 分佣协议要点
- 合作期 12 个月，自动续约；任何一方可 60 天书面退出。
- 客户首月费：**伙伴 70% / 我方 30%**（补偿获客成本），之后每月 **50/50**。
- 工程单 100% 归伙伴；我方提供免费技术咨询（≤2 小时/月/伙伴）。
- 探针硬件：我方成本价供应（$210），伙伴可转售加价或免费赠送拉单。
- 月度对账：每月 5 号出账单，伙伴 10 号前支付分成；逾期 30 天暂停服务。
- 非竞争：伙伴不得在合作期复制我方技术方案对外销售。

### 3.2 白标协议要点
- 授权费 **$99/节点/月**（年付 12 送 1 个月；>50 节点 $89）。
- 白标后台：伙伴自有域名/Logo，功能含看板、日报、报告、告警。
- 上门兜底：伙伴自建或向我方按次采购（$250/次）上门服务。
- 数据归伙伴客户所有，我方为处理者（签署 DPA）。
- 验收：伙伴 1 个真实客户跑通 30 天白标流程 → 正式放量。

## 4. 伙伴生命周期管理

| 阶段 | 我方动作 | 产出 |
| --- | --- | --- |
| 1. 招募 | 名单 20 家 → 电话/拜访 → 演示 demo | 意向伙伴 3–5 家 |
| 2. 签约 | 协议签署 + 伙伴培训（2 小时线上 + 1 次跟单） | 协议 + 手册 |
| 3. 打样 | 伙伴带 1 个客户跑通「试用→付费」 | 首个案例 |
| 4. 放量 | 月度对账 + 季度复盘 + 联合扫园 | 节点增长 |
| 5. 评估 | 季度计分卡（下表） | 升级/降级决策 |

**伙伴计分卡（季度）：**
| 指标 | 目标 |
| --- | --- |
| 新增活跃节点 | ≥3/季度 |
| 节点留存率 | ≥90% |
| 回款及时率 | 100% |
| 客户投诉 | ≤1 |

## 5. 渠道支持包（交付给伙伴）

1. **伙伴手册**：产品说明、话术、部署 SOP、报价模板（白标版）。
2. **培训材料**：2 小时录播 + 1 次线下跟单陪访。
3. **Demo 支持**：伙伴可借 demo 箱（押金 $500）。
4. **营销素材**：单页白标模板（可改 Logo）、案例集。
5. **技术热线**：伙伴专属微信群 + 4 小时响应。

## 6. 冲突与治理规则

| 场景 | 规则 |
| --- | --- |
| 客户撞单 | 先报 CRM 者得；双方 24 小时内无异议即锁定 |
| 地域重叠 | 自营与渠道**不同园区**；同一园区双方都拜访过 → 首次登记优先 |
| 伙伴私下拉走自营客户 | 合同违约条款 + 违约金（12 个月服务费 30%） |
| 伙伴品牌变自营 | 伙伴若终止白标，客户归属伙伴，我方按 $500/节点一次性买断探针资产 |
| 服务质量纠纷 | 我方监控中心记录为准；严重违约 30 天整改期 |

## 7. 渠道放量里程碑

| 时间 | 目标 |
| --- | --- |
| Month 4 | 首批 3 家伙伴签约，1 家完成打样 |
| Month 6 | 渠道节点 ≥10，渠道 MRR ≈ $1,500（我方口径） |
| Month 9 | 渠道节点 ≥20；1 家升级白标 |
| Month 12 | 渠道贡献 ≥40% 总节点；白标 SaaS 后台 v2.0 上线 |
