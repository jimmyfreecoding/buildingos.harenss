## 5. 现金流要点与纪律

| 纪律 | 规则 |
| --- | --- |
| 收款方式 | B2B 一律**月付预付**（每月 1 号扣款），年付 9 折鼓励预付；豪宅按 50/40/10 分期 |
| 现金缓冲 | 始终保留 ≥2 个月固定成本（≈$11k），动用前必须创始人书面决策 |
| 外包付款 | 里程碑验收后付款（50% 启动 / 40% 验收 / 10% 尾款 30 天） |
| 固定成本红线 | 月固定成本增幅 ≤ 上月 MRR 增幅的 50% |
| 税务预留 | 每笔收入计提 15%（销售税+所得税缓冲），QuickBooks 自动归类 |

---

## 6. 销售税要点（德州）

- 硬件销售（探针/AP/摄像头/工程设备）**征收销售税**（8.25% 休斯顿地区）。
- 监控/运维**服务费**一般**不征税**；若「设备+服务」打包销售则可能整体应税 → 合同拆分「设备/服务」两行开票。
- 注册 Comptroller 销售税号后按期申报（通常月度/季度）。
