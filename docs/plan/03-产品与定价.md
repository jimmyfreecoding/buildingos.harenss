## 3. SLA 承诺边界（话术与合同的关键）

> 对 B2B 客户承诺的是**监控与自愈服务的可用性**，不是「您的网络永不断」——合同必须写清楚，否则自愈失败时会被追责。

| 指标 | 承诺 | 备注 |
| --- | --- | --- |
| 监控可用性 | 99.5%（探针在线率） | 不承诺客户网络本身 |
| 告警响应 | 15 分钟内确认 | AI 自动确认即算 |
| 自愈执行 | 30 秒内自动执行（授权后） | 成功率 ≥90%，失败转人工 |
| 上门响应 | Basic 4h / Pro 2h（工作日 8:00–20:00） | 紧急情况不限时段 |
| 服务抵扣 | 当月 SLA 违约 → 按比例退还月费（上限 50%） | 合同条款 |
| 免责 | 因客户侧电力/光纤运营商故障、客户自行变更、不可抗力不担责 | 合同条款 |

## 4. 成本结构与毛利

### B2B 订阅单位经济（按 Basic $349 均值）
| 项目 | 金额/月 | 说明 |
| --- | --- | --- |
| 探针折旧 | $9 | $210 ÷ 24 个月 |
| 通信/云/域名 | $5 | Tailscale + 邮件 + 看板托管（本地为主） |
| 客服/值班工时 | $20 | 虚拟助理分摊 |
| **单节点可变成本** | **$34** | |
| **单节点毛利** | **$315（90%）** | ($349 − $34) ÷ $349 |
| 分摊固定成本（$5,500/月） | 18 个节点后转正 | 见 07 财务 |

### 豪宅项目毛利
- 材料/分包 20–40%，毛利 **60–80%**；$99/月托管基本为纯利。
- 风险：工期超支吞噬毛利 → 合同固定总价 + 变更单机制。

## 5. 定价锚点与话术

| 场景 | 锚点话术 |
| --- | --- |
| 报 $299 被嫌贵 | 「兼职网管每月 $3,000–$5,000 还只能白天上班，我们 24 小时盯着、秒级自愈，只要 1/10 的钱。监控断 2 小时货损就不止 $299 了。」 |
| 客户想砍价 | 报价 $399 → 年付 9 折 = $359/月，锁 12 个月；避免直接降价伤锚点 |
| 客户只要试用不付费 | 试用 14 天是固定流程，Day 12 主动电话，Day 14 现场演示报告，报告里直接带报价页 |
| 大仓库（>30k）嫌 Basic 不够 | 直接推 Pro $599，突出 2 次上门 + AI Helpdesk 帮员工省时间 |
| 豪宅业主比价 | 「市面上智能家居 90% 是无线方案，3 年后就卡顿。KNX 是德国工业标准，总线 10 年不坏，我们 10 年质保。」 |
