# 01 · 总览与执行路线图

> 目标读者：创始人、潜在投资人。本文件把「双轨商业模式」翻译成三阶段作战路线图：每个阶段的**目标、动作、交付物、责任人、退出条件（决策门）**，以及未来 90 天的第一场战役日程。

---

## 1. 战略总览

```
                       ┌────────────────────────────────────────────┐
                       │           To B 骨干业务（现金流基石）        │
                       │   10k–100k sq ft 仓储/3PL/工厂              │
                       │   $299–$899/月 AI 网管订阅                  │
                       └───────────────┬────────────────────────────┘
                                       │ 诊断报告导出工程单
       免费探针大屏（获客）──► 订阅转化 ──┼──► 二次弱电工程（CapEx）
       14 天零风险试用                   │     仓库 Wi-Fi/CCTV/门禁
                                       │
                                       ▼
                       ┌────────────────────────────────────────────┐
                       │        To C 高端延伸（利润增长极）           │
                       │   Sugar Land / Memorial / River Oaks 豪宅    │
                       │   KNX 有线总线 + 本地 AI 大脑 + 全屋托管      │
                       │   $8,000–$30,000+/次 + $99/月                │
                       └────────────────────────────────────────────┘
```

**逻辑链：** 免费探针（低信任门槛）→ 信任建立（透明大屏）→ 订阅（稳定 MRR）→ 工程单（CapEx）→ 高端住宅（高毛利）→ 渠道放量（规模化）。

**三条护城河：**
1. **信任即产品：** 「你看到的就是全部数据」的物理隔离承诺，是竞品（远程 SaaS 监控）无法复制的差异化。
2. **本地兜底：** 持牌弱电团队随时上门 → 解决 AI 不敢担责的「最后一公里」。
3. **B2B2C 导流：** 仓储客户的老板 = 豪宅业主，天然是高端业务私域池。

## 2. 三阶段路线图

### Phase 0 · 准备期（Day 1–14）— 「把枪擦亮」

| 目标 | 把公司、牌照、保险、探针、物料全部就绪，具备「第一天见客户」的能力 |
| --- | --- |
| 核心动作 | ① 注册德州 LLC + EIN + Comptroller 销售税号 ② 确认德州低电压牌照路径（见 08 合规）并锁定持牌分包 ③ 购买保险（GL/E&O/设备） ④ 探针原型打样 5 套 + 便携显示器 + 宣传物料 ⑤ 签约开发外包：MCP 工具、看板、日报/报告生成 ⑥ 法务定稿 NDA、服务协议、自愈授权书 ⑦ 建立 CRM 与邮箱/电话/网站 |
| 交付物 | 探针 demo 箱（1 台现货）、20 份单页、协议模板、CRM 字段、报价单模板 |
| 预算 | ≈ $15,000（详见 07 财务） |
| **决策门 G1** | 探针原型在自建环境 24h 稳定运行；协议模板法务过目；否则延期 |

### Phase 1 · 种子打样（Day 15–45）— 「第一份真实报告」

| 目标 | 在 1–2 个熟人仓库免费部署，拿到第一份真实《仓库健康报告》+ 大屏实物照片 + 客户证言 |
| --- | --- |
| 核心动作 | ① 锁定 1–2 个华人/熟人仓库（首选 10k–30k sq ft） ② 现场 5 分钟部署 SOP ③ 每日健康日报自动推送 ④ Day 14 输出诊断报告并做转化演示 ⑤ 全程录像/拍照（客户书面同意用于案例） ⑥ 收集反馈迭代产品（OUI 库、报告排版、中文/英文双语） |
| 交付物 | ≥1 份真实诊断报告、案例材料包、转化脚本实测数据 |
| **决策门 G2** | ≥2 个试用部署且探针稳定；报告质量客户认可；否则回到 Phase 0 修产品 |

### Phase 2 · 园区拓客（Month 2–4）— 「1 → 10」

| 目标 | 跑通「免费试用 → 付费订阅」完整漏斗，积累 8 个付费节点（MRR ≈ $2,800） |
| --- | --- |
| 核心动作 | ① 选择 Sugar Land 或 NW Houston 仓储园区，带 demo 箱扫园（每天 3–5 家） ② 每周至少 10 次冷拜访、5 台试用部署 ③ 付费转化：Day 12 电话 + Day 14 现场演示报告 ④ 首单优惠：前 3 名年付客户 9 折锁 12 个月 ⑤ 每月 1 次客户回访收集转介绍 ⑥ 同步收集第一份豪宅线索（仓库老板自宅或亲友） |
| 交付物 | 销售漏斗数据、定价实测（$299 vs $399 敏感度）、首个 Case Study |
| **决策门 G3** | ≥8 付费节点 或 MRR ≥ $2,800；否则评估定价/目标园区/话术并调整后继续 |

### Phase 3 · 渠道扩张（Month 4–12）— 「10 → 100」

| 目标 | 开放渠道合作（分佣 + 白标），将节点数推向 45–55，MRR ≈ $18k，并签下 2–3 单豪宅 |
| --- | --- |
| 核心动作 | ① 招募 3–5 家本地弱电/安防公司（五五分成 + 白标 $99–149/节点） ② 首批 1 家渠道伙伴跑通白标流程 ③ 启动豪宅业务：独立设计-施工-交付 SOP（见 03 产品） ④ 建立 7×24 监控中心值班轮换（见 09 运营） ⑤ 启动客户推荐裂变计划 ⑥ Month 12 复盘：融资/招聘/扩张决策 |
| 交付物 | 渠道伙伴手册、白标 SaaS 后台、豪宅案例 1 个、年度复盘报告 |
| **决策门 G4** | ≥40 节点 + MRR ≥ $15k → 评估是否融资、招全职现场团队、进入 Houston 以外市场 |

## 5. 三大风险与对冲（完整清单见 08）

| 风险 | 概率 | 影响 | 对冲 |
| --- | --- | --- | --- |
| 转化率低于预期（<15%） | 中 | 高 | 双园区 A/B、前 3 名年付 9 折、定价 A/B（$299/399） |
| 自愈动作引发客户网络事故 | 低 | 高 | 先只读 30 天 → 书面授权后开启 PoE 重启 → 责任限额条款 |
| 持牌分包不配合/排期冲突 | 中 | 中 | 备选分包 ≥2 家；白标伙伴即第二梯队现场力量 |
