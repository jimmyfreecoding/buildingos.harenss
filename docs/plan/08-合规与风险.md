# 08 · 合规与风险

> 目标读者：创始人、法务顾问。本文覆盖德州落地必须处理的**牌照、保险、隐私法规、合同要点**，以及完整的**风险登记册**（概率 × 影响 × 对冲）。⚠️ 本文为操作框架，具体条款请由德州执业律师/会计师定稿。

---

## 1. 牌照与资质（德州）

| 事项 | 要求与路径 | 时间/成本 |
| --- | --- | --- |
| 公司实体 | 德州 LLC（TX Secretary of State，可加急 1 天）；EIN（IRS） | $300 + $50 |
| 销售税号 | Texas Comptroller 注册并按期申报（硬件销售应税） | 免费，注册后申报 |
| 低电压施工（TECL） | 德州《Electrical Safety and Licensing Act》：商业低电压（安防/CCTV/网络布线）施工作业，承包商需 **TECL（Electrical Contractor License）**；休斯顿市另有地方电气执照要求 | 需持牌人挂靠/合作；**建议初期全部施工走持牌分包，不自持** |
| 纯监控服务 | 只插探针/远程监控不构成「电气施工」，无需 TECL；但上门排查涉及动手施工时须走持牌分包 | — |
| 住宅强电/总线 | 强电侧必须持牌电工；KNX 总线（29V SELV）属低压，但仍建议由持牌电工实施以降低责任 | — |
| FCC | 我方不制造射频设备，安装的 Wi-Fi/摄像头须为 FCC 认证成品（采购时核验） | — |
| 其他 | 无联邦承包资质要求（非政府合同）；出口管制不适用 | — |

**策略：** 公司与 ≥2 家持牌分包签框架协议；报价单与合同明确「施工由持牌分包执行」。自持 TECL 的成本（考试、担保、保险）在节点 ≥40 后再评估。

## 2. 保险清单（首年 ≈ $3,000）

| 险种 | 保额建议 | 用途 |
| --- | --- | --- |
| 商业综合责任险 GL | $1M/次，$2M 累计 | 现场事故、第三方财产损失 |
| 职业责任险 E&O | $1M | 诊断失误、自愈动作引发损失的索赔 |
| 网络/数据责任险（Cyber） | $1M（可后续加） | 数据泄露（CCTV 画面、凭据） |
| 设备/工具险 | 按实际 | 探针、demo 箱损坏 |
| 劳工险 WC | 有雇员后强制 | 聘用员工时生效 |

> 找持牌保险经纪比价（TruStage/Hiscox 等线上渠道起步）；合同要求分包自带 GL + 我方列为附加被保险人。

## 3. 隐私与数据合规

| 法规/义务 | 适用性 | 我方动作 |
| --- | --- | --- |
| **TDPSA**（德州数据隐私与安全法，2024-07-01 生效） | 处理「个人数据」的企业；B2B 网络元数据一般不构成个人数据，但 CCTV 画面含个人形象 | 隐私声明、数据最小化、处理者协议（白标 DPA）、删除响应流程（≤45 天） |
| 联邦 FTC Act（反欺诈） | 广告承诺须属实 | 话术与合同措辞一致；不夸大「永不掉线」，只承诺 SLA 内指标 |
| 录像/监控法规 | 商用场所监控一般合法；住宅须业主书面同意；不记录音频（德州两方同意录音法） | 合同含监控告知条款；探针不采集音频 |
| 合同数据条款 | 零写入承诺、数据留存 30 天、清除证明 | 见 §4 合同要点 |
| 网络安全实践 | 探针凭据加密（age）、Tailscale 出站、禁用默认口令、日志留痕 | 见 02 §3/§6/§8 |

## 4. 合同文件清单（法务定稿前框架）

1. **NDA（免费评估保密协议）**：双方互保；明确探针只读、不接触业务数据、违约赔偿。
2. **《零写入承诺书》**：一页纸，通俗中文/英文，现场签署 —— 信任卖点的法律落地。
3. **服务协议（SaaS + 托管）**：服务范围、SLA 指标与抵扣、费用与付款、**责任限额（不超过 3 个月服务费）**、**自愈授权条款**、免责（电力/运营商/客户变更/不可抗力）、终止与数据清除。
4. **《自愈授权书》**：明确授权 PoE 重启/端口隔离的具体动作与范围（默认只读 30 天后再签）。
5. **豪宅工程合同**：固定总价 + 变更单机制 + 付款分期（50/40/10）+ 保修条款（KNX 总线 10 年，设备按厂商）。
6. **渠道协议（分佣/白标）**：见 05 §3。
7. **DPA（白标数据处理协议）**：伙伴客户数据，我方为处理者。

## 6. 保险理赔场景演练（示例）

- **场景：** 自愈触发 PoE 重启导致客户生产设备（如流水线交换机）未按预期恢复，客户索赔损失。
- **应对：** ① 合同责任限额（≤3 个月服务费）兜底 ② E&O 险承保范围确认 ③ 现场记录（audit.log 完整留痕）证明按授权动作执行 ④ 24h 内响应 + 免费上门修复 ⑤ 事件复盘改进白名单规则。
