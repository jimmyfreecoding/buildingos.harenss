# 10 · KPI 与 OKR 体系

> 目标读者：全员。本文定义从「获客」到「客户成功」的指标字典、驾驶舱看板、周/月复盘节奏与季度 OKR 模板。原则：**一切指标最终服务「信任兑现」与「现金流」两个北极星。**

---

## 1. 北极星指标与健康线

| 层级 | 指标 | 健康值 | 说明 |
| --- | --- | --- | --- |
| 北极星 | **MRR + 客户续约** | MRR 月环比 +10%；续约率 ≥98%/月 | 现金流基石 |
| 第二北极星 | **NPS / 信任评分** | NPS ≥ 50；客户「会转介绍吗」≥80% 说会 | 壁垒是信任 |
| 增长先行 | 周部署试用数 | ≥5/周（Phase 2） | 漏斗顶端 |
| 变现 | 试用→付费转化率 | ≥30% | 漏斗核心 |

## 2. 指标字典（Metric Dictionary）

### 获客（Acquisition）
| 指标 | 定义 | 目标 |
| --- | --- | --- |
| 周拜访数 | 冷拜访 + 预约拜访 | 10/周 |
| 周试用部署 | 探针上线数 | 5/周 |
| 拜访→试用转化率 | 试用 ÷ 拜访 | ≥50% |
| 试用→付费转化率 | 付费 ÷ 试用（30 天内） | ≥30% |
| CAC | 获客成本（销售工时+物料摊分）÷ 新增付费客户 | ≤$600 |

### 变现与留存（Monetization & Retention）
| 指标 | 定义 | 目标 |
| --- | --- | --- |
| MRR / ARR | 月度经常性收入 / 年化 | 见 07 P&L 路径 |
| 月流失率（客户） | 当月取消 ÷ 月初客户 | <2% |
| 月流失率（金额） | 当月流失 MRR ÷ 月初 MRR | <2% |
| LTV | 平均毛利 × 平均寿命 | >$7,000（Basic） |
| LTV/CAC | | >10 |
| 升级率（Basic→Pro） | | ≥10%/季度 |
| 工程单转化（订阅客户） | 12 个月内下工程单比例 | ≥30% |

### 运营质量（Operations Quality）
| 指标 | 定义 | 目标 |
| --- | --- | --- |
| 自愈成功率 | 自愈成功 ÷ 自愈触发 | ≥90% |
| 监控可用性 | 探针在线时长 ÷ 总时长 | ≥99.5% |
| 告警确认时间 P95 | | ≤15 分钟 |
| MTTR（人工） | 平均修复时长 | ≤4h |
| 误报率 | 无动作告警 ÷ 总告警 | ≤20% |
| 报告准时率 | 日报/月报准时发送 | 100% |

### 渠道（Channel）
| 指标 | 定义 | 目标 |
| --- | --- | --- |
| 渠道节点占比 | | Month 12 ≥40% |
| 伙伴计分卡 | 见 05 §4 | 均达标 |
| 分成回款及时率 | | 100% |

## 5. 季度 OKR 模板（以 Q1 为例）

**O1：跑通「免费试用→付费」完整漏斗并验证单位经济**
- KR1：累计 ≥10 台试用部署（3 种子 + 7 园区）
- KR2：付费订阅 ≥3 个（MRR ≥ $1,000）
- KR3：实测转化率 ≥30%，CAC ≤ $600

**O2：技术平台达到可售标准**
- KR1：探针 24h 连续运行稳定性 100%（无 SD/过热事故）
- KR2：拓扑准确率 ≥90%（随机抽查 10 台设备人工核验）
- KR3：日报/报告 100% 准时自动推送

**O3：建立信任与合规基线**
- KR1：协议模板（NDA/服务/自愈授权）法务定稿
- KR2：保险全部生效 + 分包框架协议 ≥2 家
- KR3：首份客户证言 + 案例材料包上线

**O4（探索）：验证豪宅线索池**
- KR1：收集高净值线索 ≥5 个（含 1 个上门勘测）

**评分规则：** 季度末每 KR 0/0.3/0.7/1.0 打分，≥0.7 视为达成；达成率驱动下一季度投入。

## 6. 红旗预警（触发即开会）

| 红旗 | 阈值 | 动作 |
| --- | --- | --- |
| 转化率连续 3 周 <15% | 立即 | 定价/园区/话术 A/B 复盘 |
| 自愈成功率 <85% | 立即 | 白名单与 Playbook 审查 |
| 流失率 >3%/月 | 立即 | 客户访谈 + 挽回流程 |
| 现金 <2 个月固定成本 | 立即 | 停止非必要支出、催款 |
| 误报率 >30% | 周会 | 告警规则调优 |
