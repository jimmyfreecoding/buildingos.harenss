# 09 · 运营与 SLA 手册

> 目标读者：技术负责人、值班人员、创始人。本文定义 7×24 监控运营体系：监控分级、自愈 Playbook、告警规则、升级树、值班制度、日报模板、月度报告模板与探针车队运营。

---

## 1. 监控运营模型（三级）

```
 L1  AI 自动化（7×24，无人值守）         L2  值班人工（7×24）        L3  本地上门
 ┌───────────────────────────┐     ┌──────────────────────┐     ┌──────────────────┐
 │ 每 5 分钟全资产巡检         │     │ 告警确认 15 分钟内     │     │ Basic 4h / Pro 2h │
 │ 异常 → 规则判定 → 自愈      │ ──► │ 远程排查/凭据操作       │ ──► │ 持牌分包上门       │
 │ 自愈失败 / 高危 → 升级 L2   │     │ 无法远程解决 → 派单 L3  │     │ 换件/重布/修复     │
 └───────────────────────────┘     └──────────────────────┘     └──────────────────┘
```

| 级别 | 响应时间 | 职责 | 工具 |
| --- | --- | --- | --- |
| L1 AI | 30 秒内自愈 | PoE 重启、端口隔离、AP 重启、告警分级 | 探针本地规则引擎 |
| L2 值班 | 15 分钟确认 | 远程排查、凭据操作、派单、客户通知 | Tailscale + 看板 + 工单 |
| L3 上门 | Basic 4h / Pro 2h | 硬件故障、物理排查、施工 | 持牌分包调度 |

## 2. 告警规则与分级

| 级别 | 定义 | 示例 | 响应 |
| --- | --- | --- | --- |
| P1 严重 | 核心设备/全部 CCTV 离线、疑似环路风暴 | 核心交换机离线 >5 分钟 | L1 尝试 → 立即通知客户 + 派单 L3 |
| P2 重要 | 单摄像头/AP 离线、端口错误包超标 | 摄像头离线 >15 分钟 | L1 自愈（≤3 次）→ 失败转 L2 |
| P3 一般 | 性能劣化、固件过旧、弱信号 | 某 AP 负载 >85% | 入报告，次日处理 |
| P4 提示 | 信息类 | 新设备上线、固件更新可用 | 记入日报 |

**抑制规则：** 同一对象同级别告警 30 分钟内不重复推送；维护窗口（客户预约）内静默。

## 3. 自愈 Playbook（授权后生效）

### 3.1 PoE 端口重启（摄像头/AP 掉线）
```
触发：目标 3 分钟内无响应（ping/RTSP 探测均失败）
1. 快照端口状态（audit.log）
2. SNMP ifAdminStatus down → 等 10s → up
3. 重探测：成功 → 记录「自愈成功」；失败 → 计数 +1
4. 单日单端口 >3 次 → 转 P2 工单（防抖动误伤）
5. 每次动作写 audit.log（时间/对象/凭据指纹/结果）
```
### 3.2 端口隔离（风暴/环路）
```
触发：端口错误包率 >5% 持续 10 分钟
1. 记录端口 → 关闭端口 → 通知客户
2. 30 分钟后自动恢复一次；若复发 → 保持隔离 + P1 派单
```
### 3.3 AP 远程重启
```
触发：PoE 重启无效且 AP 离线
1. 尝试 SSH/云 API 重启（客户授权范围内）
2. 失败 → L3 上门
```

## 4. 升级树（Escalation Matrix）

```
L1 自愈失败 ──► L2 值班（15 分钟确认）
L2 无法远程解决 ──► L3 派单（4h/2h）
P1 且客户影响大 ──► 创始人/值班组长电话（5 分钟内）──► 客户现场通报
客户投诉/法务风险 ──► 创始人直接接管
```

| 时段 | L2 值班 | 值班组长 |
| --- | --- | --- |
| 工作日 8:00–20:00 | 虚拟助理 + 创始人 | 创始人 |
| 夜间/周末 | 创始人（Phase 1–2）；≥25 节点后外包夜间值班 | 值班组长轮值 |

## 5. 值班制度（On-Call）

- **值班日历：** 创始人为主，≥25 节点后引入兼职 NOC（月 $800，见 06 §3）。
- **值班响应：** 手机收到 P1/P2 告警 → 15 分钟内确认 → 按 Playbook 处理 → 工单记录。
- **交接：** 每次值班结束写《值班交接单》（未结工单/异常/次日提醒）。
- **月度值班复盘：** 告警量、自愈成功率、MTTR、误报率（见 10 KPI）。

```
《XX 仓库 IT/安防月度健康报告》 2026-XX
1. 执行摘要（健康分趋势、本月变化）
2. 资产清单与拓扑图（新增/移除设备）
3. 事件统计（分类、自愈成功率、MTTR）
4. 隐患清单（按优先级：P1 必须处理 / P2 建议 / P3 观察）

6. 下月计划与维护窗口
7. SLA 达成表（本月抵扣项，如有）
```

## 8. 探针车队运营

| 流程 | 规则 |
| --- | --- |
| 上架 | 镜像版本登记 → 部署 → 心跳确认 → 客户档案（CRM） |
| 监控 | 心跳 5 分钟；离线 >15 分钟 → L2 告警 |
| 升级 | 灰度 1 台 → 观察 24h → 全量（维护窗口） |
| 退网 | 拔线 → 远程 wipe → 回收 → 翻新 → 库存 |
| 审计 | 每台探针 audit.log 每月归档，客户可随时导出 |

## 9. SLA 抵扣与执行（与 03 §3 一致）

| 违约情形 | 抵扣 |
| --- | --- |
| 监控可用性 <99.5% | 当月月费 10% 抵扣 |
| 告警确认 >15 分钟 | 单次 $50 抵扣券 |
| 上门超时（4h/2h） | 当月月费 20% 抵扣 |
| 自愈错误导致损失 | 按合同责任限额协商 |
