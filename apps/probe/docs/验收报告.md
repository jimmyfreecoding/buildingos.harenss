## 5. 已知限制（诚实标注，非缺陷）

| 项 | 说明 | 解除条件 |
| --- | --- | --- |
| SNMP/RTSP 设备级验证 | 本机无交换机凭据与 ffmpeg | Pi + 客户现场（probe-image.md §8 清单） |
| DSH 无头入口 | systemd ExecStart 为模板 | Pi 首次联调按 DSH CLI 校准 |
| 持久化 | 插件内为内存事件流 | preset 版接入 store.js（M1）落盘 |
| 自愈执行 | 规则与授权门就绪，未接 SNMP 写 | 客户签署授权书 + Pi + 凭据 |
| 看板渲染 | Slot 注册已验证，视觉细节在浏览器 | GUI 内点击「看板」查看 |

## 6. 结论

**在本机可测范围内，M0–M9 全部验收通过**：发现（复刻摸盘 28 台）、端口/CCTV 识别、拓扑、规则、报告、看板、部署交付物均完成并以真实数据/单测验证。SNMP/RTSP 的**设备级**验证与 Pi 上机属于硬件依赖项，已给出明确验收清单（deploy/probe-image.md §8），可在获得 Pi 与现场交换机凭据后按清单逐项完成。
