## 主推方案 A · 六边形节点（Hex Node Shield）

**造型语言**：六边形 = 网络节点 + 盾牌 → 对应「网络 + 安防 + AI」三层定位。
**H²Z 处理（化学式风格 · 当前默认上标）**：把 `2` 做**上标**、缩小并固定着安全橙 → 化学式/科技品牌感；备选为**下标版 H₂Z**（更贴近 H₂O 的原写法）。
无论采用哪种，`2` 永远使用安全橙、永远小于 H 与 Z —— 这是品牌识别特征，也是可注册的图文商标要素。电话统一话术 **"H-two-Z"**，必要时补一句 **"like H₂O, but with a Z"**。
**描述行**：`CCTV · NETWORKS · AI MONITORING` 永远与主标识同行 —— 品牌尚无知名度时，"Tech" 不说明业务，描述行负责让客户一眼看懂。

## 排版

- **文字标识**：超黑无衬线（Arial Black / Montserrat ExtraBold / Inter Black 任一，选定后固定一种）
- **描述行**：无衬线大写 + 字距 `0.18em`
- ⚠️ **当前 SVG 使用系统字体便于预览**；正式印刷、贴膜与商标申请前必须**文字转曲（outline）**，避免字体授权与替换问题

## 使用规则

| 项目 | 规则 |
| --- | --- |
